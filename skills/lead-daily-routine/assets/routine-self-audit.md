# Routine self-audit

Area: ______ · Tier: ______ · Meetings observed (dates): ______

Score only what you saw in real meetings. Write "not observed" when you could not see it.

## 1. Performance management

| Question | Yes/No |
|---|---|
| Is each KPI specific and measurable, with a target and a time frame? | |
| Is each actual compared with its target on the board? | |
| Are deviations recorded when they happen? | |
| Does each deviation lead to an action, an escalation or problem solving? | |

## 2. Meeting process

| Question | Yes/No |
|---|---|
| Is there a written agenda? | |
| Does the meeting follow it, briskly and on purpose? | |
| Does the meeting keep to its standard duration? | |
| Is the meeting clearly aimed at targets and actions, not at reporting? | |

## 3. Problem solving

| Question | Yes/No |
|---|---|
| Is problem solving started for deviations with an unknown cause? | |
| Is each started problem solve tracked to its end? | |
| Does it follow a structured approach with standard documents? | |
| Are the problem definition and the root cause written down? | |
| Are countermeasures carried out as agreed, checked, and then made the standard? | |

## 4. Visual management

| Question | Yes/No |
|---|---|
| Does the board show the current production status? | |
| Is the agenda on the board? | |
| Is the KPI profile on the board? | |
| Is the problem solving in progress visible on the board? | |

## 5. Competence development

| Question | Yes/No |
|---|---|
| Do team members take part in solving problems, not only in reporting them? | |
| Do team members help carry out the countermeasures? | |
| Is the routine linked to competence management, for example a qualification matrix? | |

| Started on time % | started on time ÷ held × 100 | | |
| Within timebox % | ended within the timebox ÷ held × 100 | | |
| Attendance % | attendees present ÷ attendees invited × 100 | | |
| Reds with a countermeasure or escalation % | (reds with countermeasure or escalation) ÷ reds × 100 | | |
| Action closure rate % | actions closed by their due date ÷ actions due × 100 | | |
| Average open age (days) | sum of the ages of all open actions ÷ number of open actions | | |
