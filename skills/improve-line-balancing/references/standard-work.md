# Standard work

The documents that fix the new balance, how to train it, and when to re-time it.

## Three elements

Standardised work (Standardarbeit) fixes three things for each operator (LEI):

1. Takt time.
2. Work sequence: the exact order of elements within takt.
3. Standard work-in-process (WIP): the parts, including those inside machines, needed to keep the process running.

## Documents

| Document | Content | Use |
|---|---|---|
| Process capacity sheet | Per machine: automatic cycle, load and unload time, tool change interval and time, capacity per shift | Find the machine bottleneck; confirm each machine cycle fits takt |
| Standardised work combination table | Per operator: each element with manual, walk and machine time on a time scale against the takt line | Confirm the operator's cycle fits takt; redo when takt changes |
| Standardised work chart | Layout with the operator's walk path, the element sequence, standard WIP positions, quality and safety marks, takt and cycle time | Posted at the station |
| Job instruction sheet (job breakdown) | Important steps, key points and reasons; safety points are always key points | Training |

Document set and purpose after the LEI lexicon (LEI).

## Training

Train each operator in the new sequence with TWI Job Instruction (TWI):

1. Prepare the worker.
2. Present the operation, one important step at a time, with key points and reasons.
3. Try out performance: the learner does the job, then explains each step while doing it again.
4. Follow up: the learner works alone with a named helper; check often, then taper off.

If the learner has not learned, the instructor has not taught (TWI).

## Pilot and re-timing

1. Run the new balance on one shift first, with the old balance documented as a fallback (rule of thumb).
2. Track output hour by hour against plan, with a reason for every miss. Producing over plan in an hour is as much a deviation as producing under it (Rother & Harris).
3. Re-time the elements after 2–4 weeks (rule of thumb from practitioner research) and rebalance if loads changed.
4. Recompute takt and the balance whenever demand or shifts change; LEI describes a monthly takt review, with a tweak every 10 days, at one carmaker (LEI).
5. Standard work is the baseline for kaizen, not a fixed rule (LEI).
