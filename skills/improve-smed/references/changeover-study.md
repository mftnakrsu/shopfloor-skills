# Changeover study

How to film and break down a changeover, how to sort each element, which technique fits which element, and a worked example.

## Filming

- Film a normal changeover, not a rehearsed one, from the last good part of the old run to the first good part of the new run, both at normal speed (Vorne).
- One camera per person, following the person, not the machine. Keep the clock visible or use the video time stamps.
- Tell the team the study is about the method, not about them. Being watched can shorten times on the day (Vorne), so compare with the times in the production records.
- If changeover times differ by product pair (for example light to dark colour, small to large die), film the long pairs and note the sequence effect.

## Element sheet

Write one row per element, a few minutes or less each. For every row: start, end, duration, person, machine stopped or running, type, and internal or external after review.

| Type | Examples |
|---|---|
| Prepare | Fetch tool, gauge, material, paperwork, crane, cart |
| Remove and mount | Unclamp, lift out, lift in, align, clamp |
| Connect | Water, air, hydraulics, power, sensors |
| Adjust and trial | Settings, trial parts, measurement, correction |
| Verify | First-piece check, wait for approval, records |
| Wait or search | Waiting for a person or crane, searching for tools |

Walking, searching and waiting are always targets for removal.

## Sorting questions

1. Must the machine be stopped for this element? If not, it is external.
2. Is it external work that is done during the stop today? Move it out with a checklist and a staged cart.
3. Could it become external with a change: preheating, presetting offline, a second fixture or an intermediate jig? Convert it.
4. Is it still internal? Streamline it with the techniques below.

## Techniques

The eight techniques attributed to Shingo (Wikipedia), with line examples:

| Technique | Example |
|---|---|
| Separate internal from external | Pre-changeover checklist; next tool staged at the machine |
| Convert internal to external | Preheat the mould; preset tools on a presetter |
| Standardise function, not shape | Same clamp height and locating points on every die |
| Functional clamps, fewer fasteners | Quick clamps or quarter-turn fasteners instead of 8 bolts |
| Intermediate jigs | Mount the next tool on a pallet or sub-plate offline |
| Parallel operations | Two people on opposite sides of the machine |
| Eliminate adjustments | Fixed stops, pins, stored settings, setting gauges |
| Mechanise | Die carts, rollers, powered clamps, last |

Procedural changes come before tooling spend. A pass typically saves about 45% (Wikipedia) and a goal of about 50% per pass is common (Vorne); both are rules of thumb. Repeat passes toward a single-digit number of minutes, which is what "single minute" means: under 10 minutes (Wikipedia).

## Worked example

Invented round numbers. A press changeover, one setter, machine stopped throughout, 60 min.

| # | Element | Before | Change | After (internal) |
|---|---|---|---|---|
| 1 | Fetch the next die | 10 | External: staged before the stop | 0 |
| 2 | Fetch tools and cart | 5 | External: checklist and shadow board on the cart | 0 |
| 3 | Unclamp and remove the old die | 10 | Quick clamps | 4 |
| 4 | Mount, clamp and shim the new die | 15 | Standard die height, locating pins | 5 |
| 5 | Adjust and trial hits | 10 | Fixed stops and stored settings | 4 |
| 6 | Wait for first-piece approval | 10 | Inspector called at last good part, gauge staged; the check stays | 4 |
| | **Total** | **60** | | **17** |

- After separation (rows 1 and 2): 60 − 15 = 45 min, at no cost.
- After streamlining: 17 min. Saving = 60 − 17 = 43 min = 43 / 60 = 72%. This is a deliberately large example; a typical first-pass saving is about 45%.
- The approval is shortened, not removed.
