# Set-up verification

What the set-up check must contain, how to make it faster without removing it, and what to update when the changeover method changes.

## Requirements in summary

- IATF 16949 8.5.1.3, in short: any new set-up, whether a first run, a new material or a new job, is checked before the run continues, and the approval is recorded. Setters work from written guidance. Statistical checks are used where they make sense, and the first part of a run can be compared with the last part of the run before.
- IATF 16949 8.5.1.1: the control plan holds the process controls, including set-up verification and first-off/last-off validation where they apply.
- Customer-specific requirements may add to these; ask for them.

## What the first-piece check covers

1. The right tool, program, material and settings for the new product.
2. The characteristics named in the control plan for set-up, measured with the stated gauge.
3. A comparison with the last-off part of the previous run of this product, where kept.
4. A record: who approved, when, results, decision.

## Making it faster, not shorter on content

| Waste | Fix |
|---|---|
| Waiting for the inspector | Call at the last good part of the old run; fixed release window |
| Fetching gauges and drawings | Staged at the machine before the stop |
| Measuring in the lab | Go/no-go gauges or a setting gauge at the machine, where the control plan allows |
| Repeated trial parts | Remove adjustments (stops, stored settings) so the first part is good |
| Last-off check during the stop | Do it as external work on the last part of the old run |
| One approver for many machines | A trained, released person at the machine, where local rules and the customer allow |

## Risk of producing before approval

Everything made after the set-up and before approval is suspect. If the check fails later, all of it must be blocked and sorted. Never let a time target remove the check; shorten the wait instead.

## When the method changes

- Update the set-up instruction and the changeover standard.
- Update the control-plan row if the check, gauge or frequency changes.
- Review the PFMEA when the change affects a failure mode, for example removing an adjustment.
- Train and release the setters on the new method, and keep the records.
