# Brand working files

Everything under `assets/brand/`, the plugin icon `.claude-plugin/icon.png`, and the logo, favicon and diagram files of the docs site are generated by the tools in this folder. The guidelines are in [assets/brand/BRAND.md](../../assets/brand/BRAND.md).

| Path | What it is |
|---|---|
| `tools/build_brand.py` | Builds the logo files, the animated SVGs, the favicon SVG and the social preview source. Also writes the logo and favicon copies in `docs-site/` |
| `tools/render_fallbacks.py` | Renders the GIF and PNG fallbacks, the favicon PNGs and ICO, the web-app icons, `social-preview.png` and `.claude-plugin/icon.png`. Copies the web icons into `docs-site/public/` |
| `tools/build_handoff_loop.py` | Builds `docs-site/public/hand-off-loop.svg`, the hand-off loop diagram. Standard library only |

## Rebuild

Requirements: Python 3.10+, `fontTools`, `cairosvg` (which needs the Cairo library) and `Pillow`. They are needed only to rebuild brand files, not to use the skills.

```bash
# 1. Fetch the two Barlow Semi Condensed fonts (SIL Open Font License 1.1). They are not stored in this repository.
mkdir -p /tmp/barlow
for f in BarlowSemiCondensed-SemiBold.ttf BarlowSemiCondensed-Medium.ttf; do
  curl -sSL --max-time 30 -o /tmp/barlow/$f https://raw.githubusercontent.com/google/fonts/main/ofl/barlowsemicondensed/$f
done

# 2. Install the Python packages, for example in a virtual environment.
python3 -m venv /tmp/brand-venv && /tmp/brand-venv/bin/pip install fonttools cairosvg pillow

# 3. Build the SVG files, then the raster files. Run from the repository root.
FONTS="--semibold /tmp/barlow/BarlowSemiCondensed-SemiBold.ttf --medium /tmp/barlow/BarlowSemiCondensed-Medium.ttf"
/tmp/brand-venv/bin/python design/brand/tools/build_brand.py $FONTS
/tmp/brand-venv/bin/python design/brand/tools/render_fallbacks.py $FONTS

# 4. The diagram needs nothing but Python.
python3 design/brand/tools/build_handoff_loop.py
```

## Change something

- Colours, symbol geometry, tagline and sizes are constants at the top of `tools/build_brand.py`.
- Animation timing is in the `animation` section of `tools/build_brand.py`. The GIF frames use the same constants, so the fallbacks match the SVG.
- When a skill ships, update `AVAILABLE` and `SOON` in `tools/build_handoff_loop.py` and run it again.
- After a change, rebuild, look at every file on a light and a dark background, and commit the generated files with the tool change.
