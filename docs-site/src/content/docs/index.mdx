## What it is

A skill is a folder of plain markdown that your coding agent reads when a task needs it. Each skill here holds one shopfloor method as a procedure: the inputs to ask for, the steps, the checks to run before answering, and a template for the result. Definitions, formulas and sources sit in reference files next to it.

A subagent is a specialist that your agent can hand a whole job to, such as leading an 8D or reviewing a new skill.

## How the skills are written

- **Procedures, not textbooks.** Steps, thresholds and decision rules, with a worked example where there is a calculation.
- **Every number has a source or a label.** A value is cited in a reference file, or marked "rule of thumb" or "set by local policy".
- **Ask, don't invent.** When an input is missing, the skill asks for it or states its assumption.
- **Standards are pointers.** A clause number plus a summary in our own words. Never the text of the standard.
- **No names.** No employer, plant, customer, product or person names in any skill, agent or test case.

## Install

In Claude Code:

```
/plugin marketplace add mftnakrsu/shopfloor-skills
/plugin install shopfloor-skills@shopfloor-skills
```

OpenCode, Qwen Code and Cursor use a small installer, and any tool that reads Agent Skills can take the skills with `npx skills`. See [Install](/start/install/) for every method.
